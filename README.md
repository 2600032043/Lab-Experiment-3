
# Lab Experiment 3: Responsive Layout with Grid & Flexbox

## Project Title
BiteBox - Online Food Ordering and Restaurant Discovery Website

## Objective
To develop a mobile-first responsive food ordering webpage using CSS Grid and Flexbox, providing users with an interactive platform to explore food categories and restaurant listings.

## Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Media Queries
- Container Queries

## Features
1. Responsive website header and navigation bar.
2. Hero section introducing the food ordering platform.
3. Popular food categories.
4. Six restaurant cards with images and descriptions.
5. CSS Grid-based restaurant listing layout.
6. Hover effects and interactive styling.
7. Mobile-first responsive design.
8. Media queries for mobile, tablet and desktop layouts.
9. Container queries for adaptive restaurant cards.

## Project Structure

Lab-Experiment-3/
│
├── index.html
├── style.css
└── README.md

## Responsive Breakpoints

- Mobile: Below 600px
- Tablet: 600px to 899px
- Desktop: 900px and above

## Implementation Details

### CSS Flexbox
Used for:
- Header and navigation alignment.
- Hero section layout.
- Food category arrangement.

### CSS Grid
Used for:
- Displaying six restaurant cards.
- Creating responsive columns based on screen size.

### Media Queries
Used to adjust layouts for mobile, tablet and desktop screens.

### Container Queries
Used to adapt restaurant card styling according to the available container width.

## Testing
The webpage will be tested across:
- Mobile devices
- Tablets
- Desktop screens

## Conclusion
The experiment demonstrates the use of CSS Grid and Flexbox to create a responsive and user-friendly food ordering website that adapts to different screen sizes.
